# Iris Flower Classification using Machine Learning

## Overview

This project focuses on classifying iris flower species using Machine Learning techniques. The model predicts the species of iris flowers based on features such as sepal length, sepal width, petal length, and petal width.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Machine Learning Algorithm

* Logistic Regression / Random Forest / K-Nearest Neighbors

## Dataset

The project uses the famous Iris Flower Dataset containing three species:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## Features

* Data preprocessing
* Data visualization
* Model training and testing
* Accuracy evaluation
* Prediction system

## Project Objective

To build a Machine Learning classification model that accurately predicts iris flower species based on flower measurements.

## Results

The model achieved high classification accuracy and successfully classified iris flower species using Machine Learning algorithms.
